# Publications Solace

Images et vidéos **déjà prêtes à publier** sur les réseaux de Solace. Ce dépôt est public
exprès : Metricool doit pouvoir lire les fichiers pour les envoyer à Instagram et TikTok.
Rien de privé ici (pas de voix brute, pas de fichier de travail, pas de secret).

## Rangement

```
carrousels/<date>-<nom>/fr/01.jpg, 02.jpg, ... + LEGENDE.txt
carrousels/<date>-<nom>/en/...                  (publié à la main)
videos/<date>-<nom>/fr.mp4, en.mp4 + LEGENDE-fr.txt, LEGENDE-en.txt
```

- Images : JPEG carré 1080 × 1080 (Instagram et TikTok acceptent le JPEG, pas toujours le PNG).
- Vidéos : MP4 1080 × 1920, moins de 100 Mo par fichier (limite de GitHub).
- Lien direct d'un fichier, à donner à Metricool :
  `https://raw.githubusercontent.com/eunoiaappelite-beep/solace-publications/main/<chemin>`

## Qui publie quoi

- Français : Claude programme dans Metricool (Instagram, TikTok ; YouTube pour les vidéos),
  seulement après accord sur le jour et l'heure.
- Anglais : publié à la main par l'équipe Solace (images + `LEGENDE.txt` à copier-coller).

## Ménage

GitHub gratuit : rester sous 1 Go. Une fois un post publié et en ligne depuis quelques jours,
on peut supprimer son dossier ici.

Les fichiers sont fabriqués dans le dépôt de l'application (`marketing/studio/`).
